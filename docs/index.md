## 使用方式

先看 [简历诊断](/resume-map)，知道哪些地方最容易被问；再看 [知识地图](/knowledge-map)，按优先级补基础；最后用 [相似项目案例](/projects/case) 和 [面试问答](/interview-qna) 练表达。

这份站点面向“小白准备面试”的场景，不追求把每个技术讲成百科，而是优先帮你回答：这项技术是什么、为什么项目里要用、你具体做了什么、出了问题怎么排查。
