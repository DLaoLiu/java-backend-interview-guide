# Java 后端面试复习站

这是一个 VitePress 文档站点，用于把简历中的 Java 后端、大数据、分布式和 AI API 集成经历拆成可复习、可背诵、可演练的面试材料。

内容以 JavaGuide 公开页面为主要出处，结合简历项目做学习清单、追问地图、相似案例和回答模板。站点不包含手机号、邮箱等个人隐私信息。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## GitHub Pages

仓库名建议使用 `java-backend-interview-guide`。本项目已配置 `.github/workflows/deploy.yml`，推送到 GitHub 后可使用 GitHub Actions 部署 Pages。
